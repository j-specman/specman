Specman @VERSION@ (portable)

This directory contains everything needed to run Specman without installing anything:

  • specman.bat / specman.sh - starts Specman (Windows / Linux)
  • specman-@VERSION@-jar-with-dependencies.jar - the application itself
  • SpecmanModel_V002.g4 - the grammar of the .nsd file format, for AI-agent-assisted spec authoring
  • specman-reference-*.nsd - a reference model matching this grammar version

The full manual is maintained online and keeps growing:
https://github.com/j-specman/specman/blob/master/doc/specman-manual.adoc

Note: that link always points to the latest state on the master branch, which may already describe features newer than this Specman @VERSION@ release.
